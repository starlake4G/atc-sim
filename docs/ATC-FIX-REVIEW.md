# 游戏问题与本轮修复

2026-10-18。本轮检查了仿真状态机、指令校验、资源清理，并运行浏览器交互回归。保留现有机场、关卡和操作方式。

## 发现并修复

| 问题 | 原因与修复 |
| --- | --- |
| 选择朝北/朝西推出后一直远离机场 | 原代码把机头朝向当作推出运动方向，航路进度无法增加。牵引运动现在沿推出路线，四种朝向都能完成离场。 |
| 退出可能触发 DOM 删除异常，重开保留标签与 GPU 资源 | 删除手动与 effect 的重复销毁路径，使销毁可重复调用；清理标签、几何、材质、纹理及监听。移除无实际工作的第二个动画循环。 |
| 高度或横向偏差很大也直接算落地 | 跑道入口处检查高度、横向偏差和航向；不稳定进近复飞并计入统计。 |
| 下达落地许可后还可以批准其他飞机进跑道 | 落地许可预留跑道，落地、进跑道和起飞共用互锁校验；增加取消落地许可。脱离时机尾清空道面后再释放跑道。 |
| 进跑道途中追加起飞许可，在滑行道上就开始加速 | 先记录许可，完成进跑道及对正后才开始起飞滑跑。 |
| 滑跑减速停在出口前，或选择已错过的出口后位置倒退 | 统一实际减速度与出口距离计算，减速后保持滑行速度；仅允许选择前方能安全减速到达的出口。 |
| 进近和离场速度指令不生效，取消进近后状态不一致 | 自动速度控制考虑玩家目标速度；航向/直飞取消进近时恢复引导阶段。 |
| 飞过跑道后无法重新直飞 IAF | 原自动逻辑每帧覆盖玩家路线。改为一次提示，保留玩家的重新引导指令。 |
| 机位被占阻塞后续所有航班，满位时重复分配 | 分别检查每个到期航班，不让等待机位的离场航班阻塞进场；满位返回等待状态；滑入期间预留机位。 |
| 无效 URL 参数白屏或极大快进参数长时间阻塞 | 未知关卡回到可操作的选关页，快进限于班次长度，排除非有限数值。 |
| 无线电达到 60 条后不再自动滚动 | 使用最后一条消息 ID 触发滚动。补充日志容量限制、提示过期和快照嵌套对象隔离。 |

## 体验优化

- 增加可点击及键盘选择的空域雷达，显示飞机、呼号、高度、航路点与选中航路。
- 地面图可点击选机；航班卡改为两行，减少长状态文本挤压。
- 显示跑道空闲/占用/落地预留、风向风速、班次剩余时间与最近事件。
- 指令栏显示阶段性操作提示；未建立进近或跑道被占时禁用相应许可按钮，并提供原因。
- 调整左右窗口与底部指令栏，验证 1280×720 和 1024×768 下不重叠；保留视角及倍速快捷键，避免干扰有焦点的按钮。
- 修正跑道两端标号，正常落地不再误标红色冲突；结算增加复飞次数。
