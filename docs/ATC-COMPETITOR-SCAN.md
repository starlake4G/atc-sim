# ATC 模拟游戏 —— 同类产品调研

> 调研日期 2026-09-27 · 配套文档 `ATC-SIM-PLAN.md`
> 覆盖商业竞品（PC / 移动 / Web）、开源项目、以及对手的失败点。

---

## 0. 结论先行

**1. 双视角不是差异化壁垒，是入场券。**
PC 端 Tower! Simulator 3 早就是"3D 塔台 + 2D GUI"，移动端 Unmatched ATC 有"含机内 6 个视角的几十种 3D 视角"，2026 年 9 月刚发行的 Airport Control 27 是纯 3D 全流程模拟。**我们方案里当作卖点的"双视角"，在品类里已经是标配。**

**2. 真正的空白在 Web 端。**
PC 和移动端都有成熟的双视角产品，Web 端现有的（atc-sim.com、ProjectATC、各类 HTML5 小游戏）**全部是 2D 雷达或休闲画线，没有一个成熟的"3D 塔台 + 2D 雷达"产品**。这是我们唯一清晰的切入口。

**3. 必须正视品类天花板。**
Endless ATC —— 这个品类口碑最好的产品，97% 好评 —— Steam 月均在线 **12～15 人**。这是个典型的"高口碑、低规模"品类。做商业项目要谨慎，做作品集/内网玩具/练手项目则是绝佳题材。

## 1. 商业竞品全景

| 产品 | 平台 | 视角 | 拟真度 | 口碑 | 关键情况 |
|---|---|---|---|---|---|
| **Tower! Simulator 3** | PC | 3D 塔台 + 2D GUI | 硬核 | Steam **68%**（约 1000 评测，褒贬不一） | FeelThere，2022-12。11 机场 + 31 个 DLC。语音识别是招牌也是最大槽点 |
| **Endless ATC** | PC / Android | 纯 2D 雷达 | 硬核机制 + 易用操作 | Steam **97%**（515 评测） | startgrid，2017。9 机场。**月均在线仅 12～15 人** |
| **Unmatched ATC** | Android / Windows | 多 3D 视角 + 2D 操作 | 中等 | **3.9 / 5**（16.5 万评价） | Vector3D，2015 至今。**1000 万+ 下载**，移动端霸主。UATC2026 在开发 |
| **Airport Control 27** | PC | 纯 3D | 硬核 | 2026-09-21 刚发行，暂无评分 | **中国团队 CCC Games**，Unity。前作 Mini Airways。见下文详述 |
| **I Am an ATC 4** | PC | 3D + 2D | 中等 | 中上 | 日本 TechnoBrain。场景化，被批"像解谜 / 缺重玩性" |
| **Airport Madness 3D** | PC / 移动 | 3D 塔台视角 | 休闲 | 良好 | 便宜、机场多、玩法爽快。简化通话术语，不硬核 |
| **ATC Ground Point** | PC | 2D | 中等 | **3.3 / 5**（51 评测） | 只做地面管制，规模很小 |
| **ATC Simulator 2 / ATCpro** | PC | 2D 雷达 | 硬核 | 老产品 | 界面过时，有兼容性问题 |

### 重点竞品：Airport Control 27（最需要盯的对手）

2026 年 9 月 21 日 Steam 发行，发行当天社区中心已有 4,748 名成员。Unity 开发，卖点：

- 1:1 真实机场设施（廊桥、ILS/PAPI/跑道灯光全套、道面标记、机型限制）
- **双语动态无线电**：AI 生成 ATC 与飞行员复诵，实时镜像你的指令，中英文可切
- 完整 SID / STAR / APP 程序，含高度与速度限制
- 地面处理自由度（推出位置、跟随前机、line-up and wait、中断起飞、高速脱离）
- **真实航空公司涂装**（竞品通常因授权问题回避）+ Steam Workshop 分享涂装/机型/机场/航班计划
- 4K / 超宽屏

**判断**：它在"拟真"这条轴上已经做到顶了，而且踩中了国内开发者做真实涂装的优势。**不要在拟真度上和它正面竞争。**

## 2. 开源项目（可借鉴的资产）

这是本次调研最有实用价值的部分。

### BlueSky —— TU Delft，学术标准 ATC 模拟器

- 语言 Python 3（numpy + pygame 或 Qt/OpenGL），MIT 许可，3000+ commits，持续活跃
- 飞机性能模型、FMS（LNAV / VNAV）、自动驾驶、**冲突探测与解脱**、机载间隔保障
- **兼容 BADA 3.x 性能数据**；全球导航台与机场数据；场景文件 `.SCN` 可回放
- 支持无头模式（headless），可批量跑仿真

→ **这是冲突检测算法和飞机性能模型的最佳参考。** 建议直接读它的冲突探测实现，而不是自己从零推。

### vice —— mmp/vice，Go 写的虚拟 ATC 模拟器

- Go + SDL2，2026 年 9 月仍在更新
- 自带 STT/TTS（语音识别与合成）、DME 弧、多场景批量测试

→ **参考它的空域/管制程序数据结构和通话用语（phraseology）的组织方式**，以及 STT/TTS 的工程做法。

### Autonomous-ATC —— BlueSky 的强化学习分支

- 深度多智能体强化学习做自动管制，附论文

→ 用处不大，但如果你想做"AI 副驾驶"或自动流量生成，这里有多智能体训练思路。

> 三者技术栈都不是 Web，**不能直接改造成游戏**，但算法与数据可直接移植。

## 3. Web 端现状（我们的机会区）

| 产品 | 视角 | 情况 |
|---|---|---|
| atc-sim.com | 2D 雷达 | 浏览器免插件，4 个机场（KORD / EHAM / KJFK / RJBB） |
| ProjectATC | 2D 塔台 + 雷达 | 真实美国机场（KSAN 免费），25 个任务职业模式，飞行员会犯错 |
| 各类 HTML5 小游戏 | 2D 休闲 | 拖拽画航线避碰，纯休闲，无拟真 |

**结论：Web 端没有任何一个成熟的"3D 塔台 + 2D 雷达"产品。** 现有产品要么是纯 2D，要么是休闲画线。

而且 Web 形态天然克制品类的最大痛点——**下载门槛**。ATC 是个"想试一下"的需求，没人愿意为它先下 20GB。

## 4. 对手的失败点 = 我们的机会清单

这份清单比竞品功能表更有价值，因为它直接指向可赢的位置。

| 对手的问题 | 证据 | 我们的对策 |
|---|---|---|
| **上手门槛过高、没有教程** | Tower!3 被批"不翻开 PDF 就玩不下去"，官方只能靠 YouTube 补课 | **渐进式引导**：第一关只教 1 架飞机降落，逐步加复杂度 |
| **语音识别不稳定** | Tower!3 对非标准呼号、非母语口音、"taxi via" 类真实短语识别差 | **鼠标 / 键盘优先，语音作为可选**，不作为核心机制 |
| **经济系统吃相难看** | UATC 被大量差评："要玩一年才解锁下一个机场"、"金币无故清零" | **不做货币化进度系统**。所有机场和内容直接开放 |
| **缺乏重玩性** | I Am an ATC 4 被批"像时间表解谜，通关即死" | **随机交通 + 自适应难度**（已在原方案） |
| **拟真度军备竞赛** | Airport Control 27 已做到 1:1 设施 + 真实涂装 + Workshop | **主动退出这条赛道**，主打低门槛和即时可玩 |
| **界面过时 / 兼容性问题** | ATC Simulator 2、ATCpro 在老系统上出问题 | Web 形态天然规避，但要注意旧浏览器回退 |

## 5. 对原方案的影响

架构不用改，但**产品定位要修正**：

| 原方案表述 | 修正后 |
|---|---|
| "我们的差异化点就是双视角" | 双视角是**入场券**，不是壁垒。差异化改为：**Web 端零门槛 + 双视角 + 中等拟真** |
| 拟真度走"中等" | **坚持，且要加强**。硬核区已被 Endless ATC / Tower!3 / Airport Control 27 占满 |
| 主打硬核玩家 | **改打"好奇但没入门"的大多数**，硬核玩家从 Endless ATC 那里抢不过来 |

**建议的定位坐标**：偏休闲易上手（不放弃机制真实性）× 强 3D 视景表现 × 浏览器即开即玩。

这个位置上目前只有 Airport Madness 3D（2015 年代的产品，画面老旧、机制简化过度），**是空位**。

---

## 6. 一句话总结

> 这个品类的空白不在"做什么"，而在"给谁做"。
> PC 和移动端已经把硬核玩家吃干净了，**Web 端那个"点开链接就玩、看得见飞机落地、不用背术语"的位置还空着。**
