# Kestrel Approach

浏览器里的全流程机场管制游戏。3D 机场、地面路线工作台、空域排序、席位移交与班次复盘共用同一套仿真状态。

## 运行

```bash
npm install
npm run dev        # http://localhost:5173，同时监听 0.0.0.0，局域网可直接访问
npm run typecheck
npm run sim:test   # 无头仿真回归（不需要浏览器）
npm run gameplay:test # 全班次/密集交通/标准模式/模型尺寸回归
npm run planning:test # 计划排序、真实许可与起飞窗口
npm run challenge:test # 种子班表与完整挑战班次
npm run edge:test  # 机位预留、交接与相向合流边界
npm run experience:test # 请求推进、调度回放、延误归因与飞机姿态
npm run operations:test # 运行事件、风况限制、策略差异与完整回放
npm run decisions:test # 窗口余量、无副作用试排、待定边界与采用回放
npm run accept     # 类型检查 + 八组逻辑回归（108 项）
npm run ui:test    # 先启动开发服务器；浏览器交互回归（需 Chrome/Edge）
npm run build
```

> 开发与预览服务都绑 `0.0.0.0`（见 `vite.config.ts`）：同一局域网的手机 / 另一台机器用 `http://<本机IP>:5173` 即可打开。
> 如果外部设备连不上，是 Windows 防火墙拦了 node.exe 的入站，放行"专用网络"即可。

## 操作

| 操作 | 说明 |
|---|---|
| 点击飞机 / 点击标牌 / 点击右侧列表 | 选中航班 |
| 底部指令条 | 只显示当前阶段可用的管制用语 |
| E / N | 下达当前高亮的许可 / 选择下个待办航班 |
| 下一请求 | 无待办时推进至新请求、安全决定或运行事件变化，最多 5 游戏分钟；不会自动许可 |
| 空格 | 暂停 / 继续 |
| 1 / 2 / 4 | 时间倍速（1× = 每 10 现实秒走 1 游戏分钟） |
| F1 / F2 / F3 | 塔台（全场） / 跟机 / 俯瞰 |
| V / 专注视图 | 桌面扩大机场画面；保留右侧待办与底部许可，地面/雷达/无线电按需打开，偏好自动保存 |
| Tab | 循环选机 |
| Esc | 关闭工作台 / 取消选中 |
| 滚轮 / 拖拽 | 缩放 / 环绕视角 |
| 布局编辑 | 拖动窗口标题、拖右下角缩放；自动保存，可恢复默认布局 |
| 画质 / 提示音 | 节能、均衡、精细三档；提示音默认关闭，可手动启用 |

## 玩法

- **标准进场**：引导 / 空中等待排序 → ILS 进近 → 联系塔台 → 落地 → 脱离 → 联系地面 → 批准滑入机位。
- **标准离场**：推出 → 等待滑行许可 → 推荐 B 路线或地图规划 C 旁通道 → 跑道外等待 → 联系塔台 → 进跑道 / 起飞 → 移交离场。
- **辅助模式**：自动处理常规滑行，保留起降排序和安全约束，适合初次体验。
- **地面通行**：有向滑行道路和路段预约；等待原因直接显示。满位时，落地机先脱离至等待点，再等待兼容机位。
- **跑道互锁**：物理占用、落地预留与游戏尾流间隔共同限制许可。
- **起飞窗口**：短五边的剩余时间必须容纳进跑道、滑跑、爬升释放和间隔缓冲，未获落地许可的来机同样会受到保护。
- **跑道计划**：点击顶部「跑道计划」加入航班，拖动或用箭头调整顺序，比较预计占用窗口和延误。计划非空时按队首放行；已获许可的顺序锁定，复飞会取消原位置。计划不自动下指令。
- **试排比较**：未承诺航班可用「试排 ↑」预览与前机交换的结果，同时比较累计预计延误、末架释放时间和每架航班的得失。预览不改实际顺序、不写回放记录；点击「采用这个顺序」才进行一次改序。任一方案含待定航班时不计算总量优劣，直接说明等待原因。
- **进近时间余量**：离场待命时显示约束来机及完整起飞窗口余量，含进跑道/滑跑、爬升释放、2 NM 与 5 秒缓冲。取所有进近来机中最小的余量；可展开查看计算。正余量仍可能被跑道占用、尾流、风况、检查、计划顺序或席位条件阻止，许可按钮继续使用同一守卫。没有进近来机时明确说明，不显示无限窗口。
- 落地许可会预留跑道；可通过「取消落地许可」释放。建立进近前或跑道被占时，相关按钮不可用，悬停可查看原因。
- 左侧空域雷达可选择远处的飞机，地面图可点击选机；底部显示当前阶段的下一步提示。
- 8 个班次覆盖单机进场、地面离场、交汇、高峰、密集波次、黄昏重型机、种子挑战与运行窗口；所有航班处理完成即可提前收班。
- **运行窗口挑战**：32 游戏分钟、8 架航班。跑道检查提前预告，可点击「利用空档 · 现在检查」提前安排；到计划时刻暂停新的起降许可，已许可飞机完成并清空后再开始检查。倒计时结束自动恢复，可继续安排地面和空中等待。
- **阵风选择**：运行窗口关的西南阵风持续 4 游戏分钟。按阵风分量与机型检查新的跑道许可；游戏侧风限制为轻型 15、中型 24、重型 28kt，顺风限制 10kt。受限 AT72 可等待，把可用喷气机调整到计划前面。已进入跑道或已获落地许可的航班保留执行窗口。
- **三向合流挑战**：35 游戏分钟、12 个航班，从 ORVIN / ESTRA / SOVIN 三处入口分层进入。菜单可输入或更换种子，同种子重现相同航班表，最好成绩按种子、规则版本和模式分别保存。
- 班次按完成量、完整滑入、离场移交、安全和平均延误评级，记录事件复盘与各模式最好成绩。安全复飞本身不扣分。生成受机位占用而推迟也会计入原计划延误。
- **调度复盘**：逐航班列出实际起降时刻、延误与主要等待类别，给出下一班建议。归因按超出目标后的仿真状态估计，完成航班的分类时间合计与实际延误一致。
- **回看调度**：结算后重放本班已接受的许可、跑道计划与提前检查操作，固定事件和天气随时间重建。支持播放、暂停、时间轴跳转和逐条操作查看；可以切换镜头和选机，成绩不受回放影响。可导出当前版本的 JSON 调度记录；当前界面暂不支持导入外部记录。
- **界面**：场景、地图、航班与指令分区；许可区域随内容自动调整，窄屏一次显示一个工作台面板，桌面浮窗布局在窄屏下暂时收起并保留。
- **场景**：道面分层、草地纹理、林地、服务车辆、机场道路与停车区；飞机显示转弯倾斜、升降姿态、发动机细节和航灯。地形细分修复低角度近景的道面遮挡。
- **运行可视化**：风袋随模拟风向和风速摆动；检查时地面图与三维跑道出现关闭标记，检查车只在实际关闭期间巡查。暂停与回放跳转使用相同模拟时间。
- 尾流与目标时刻是游戏调参，不作为真实空管标准。完整差距分析与后续计划见 `../docs/ATC-PLAYABILITY-PLAN.md`。

## 目录

视觉样板包括按机型长度构图的跟机镜头、局部精细阴影、天空环境反射、按世界尺度铺设的道面纹理与轮迹、航站楼分格玻璃与机位标牌，以及飞机曲面座舱、涂装和翼面/起落架细节。昼/暮/夜照明按创建场景时的游戏时刻选取；本轮尚未加入跨时段连续过渡或新的夜间关卡。

节能档及调试 `lite=1` 关闭环境反射、道面凹凸/粗糙度贴图和阴影，保留基础表面、标线与必要灯光。均衡/精细档展示完整样板；切换时释放旧天空与反射资源。

```
src/sim/      纯逻辑仿真（10Hz 定步长，禁止 import three/react）
src/data/     机场与关卡数据（加内容看 ../docs/CONTENT-GUIDE.md）
src/views/    three.js 场景
src/ui/       React 界面
scripts/      无头回归测试
```

## 调试参数

`?level=tutorial&fast=540&bot=1&lite=1&view=tower` —— 详见 `../docs/CONTENT-GUIDE.md` §3。

默认 URL 调试使用辅助模式；加 `&mode=standard` 检查手动滑行与移交流程。`bot=1` 只在快进阶段执行，正常游玩不会持续替玩家管制。

同种子挑战：`?level=seed-challenge&seed=KESTREL-2026&mode=standard`。快进和机器人用于检查，分享正常挑战时无需加这两个参数。

浏览器回归可指定服务器地址：`npm run ui:test -- http://localhost:5174`。包含完整手动进离场、地图节点规划、持久成绩与视觉截图，可能需要数分钟；截图保存在 `.tmp/`。非默认位置的浏览器可用环境变量 `CHROME_PATH` 指定。

跑道计划与种子界面回归：`node scripts/planning-ui-test.mjs http://localhost:5174`。

新界面与回放回归：`npm run experience:ui:test -- http://localhost:5174`。包含完整手动进场、快进到请求、记录导出、回放往返、画质与提示音、桌面/窄屏操作，以及跟机道面的实际像素检查。

运行事件界面回归：`npm run operations:ui:test -- http://localhost:5174`。包含八关菜单、提前检查、倒计时恢复、受风限制与排队原因、运行复盘及桌面/窄屏布局。

调度决策界面回归：`npm run decisions:ui:test -- http://localhost:5174`。包含真实班次试排/采用/回放、重轻型尾流代价、待定与锁定、正负窗口、正余量下的侧风限制，以及三尺寸中展开计算与手机直接采用操作。重轻型固定对比画面使用隔离的暂停测试场景。

视觉与专注视图验收：`npm run visual:ui:test -- http://localhost:5174`。包含实际场景占比、工具与许可可达性、视图偏好、窄屏切换和多时段截图。夜间图使用隔离照明场景，不代表已新增夜间关卡；无头软件渲染耗时不代表目标设备帧率。
